# 이우권 작가 · 작품 통합 목차 페이지 (`author-hub`)

## 배포
- **GitHub Pages**: `main` 브랜치 루트(`/`) 정적 배포
- **Netlify**: `netlify.toml` (`publish = "."`) 포함 — Netlify 대시보드에서 이 GitHub 저장소를 연결하면 `git push` 시 자동 배포됩니다.
